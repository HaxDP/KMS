# лекція 16

## 1

записи таблиці

```
10.0.0.0/8
10.20.0.0/16
10.20.5.0/24
0.0.0.0/0   default
```

пакет для 10.20.5.10 підпадає під усі чотири записи

| запис | чи підпадає | довжина префікса |
|---|---|---|
| 10.0.0.0/8 | так | 8 |
| 10.20.0.0/16 | так | 16 |
| 10.20.5.0/24 | так | 24 |
| 0.0.0.0/0 | так, збігається з будь-якою адресою | 0 |

за правилом найдовшого збігу префікса обирається запис із найбільшою довжиною маски

буде обрано запис 10.20.5.0/24, бо він найточніше описує мережу призначення

запис за замовчуванням завжди програє, бо маска /0 найкоротша
