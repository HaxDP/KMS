# самостійна робота №6

варіант 3 - адреса 32 біти, сторінка 4 КБ, PTE 4 Б, віртуальна адреса 0x00403ABC, TLB на 4 записи з LRU, послідовність 0 1 0 2 1 3

## 1 біти offset і VPN

offset_bits = log2 від 4 КБ = log2 від 4096 = log2 від 2^12 = 12

vpn_bits = розрядність адреси - offset_bits = 32 - 12 = 20

## 2 розмір однорівневої таблиці сторінок

2^vpn_bits * розмір PTE = 2^20 * 4 Б = 4194304 Б = 4 МБ

## 3 розбиття адреси

0x00403ABC = 4209340

VPN = 4209340 div 4096 = 1027, тобто 0x403

offset = 4209340 mod 4096 = 4209340 - 1027 * 4096 = 2748, тобто 0xABC

перевірка бітами - 0x00403ABC, старші 20 біт це 0x00403 = 1027, молодші 12 біт це 0xABC = 2748

## 4 трансляція

номер фрейму = VPN + 0x100 = 0x403 + 0x100 = 0x503, тобто 1283

фізична адреса = 0x503 * 0x1000 + 0xABC = 0x503000 + 0xABC = 0x503ABC

## 5 TLB на 4 записи з LRU

список від найдавнішої до щойно використаної

| звернення | TLB до | результат | TLB після |
| ------------------ | -------- | ------------------ | -------------- |
| 0                  | -        | M                  | 0              |
| 1                  | 0        | M                  | 0 1            |
| 0                  | 0 1      | H                  | 1 0            |
| 2                  | 1 0      | M                  | 1 0 2          |
| 1                  | 1 0 2    | H                  | 0 2 1          |
| 3                  | 0 2 1    | M                  | 0 2 1 3        |

рядок - M M H M H M
